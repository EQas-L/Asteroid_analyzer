Анализатор для игры с астероидами.
берет снапшоты из файла формата jsonl и на основе их выводит краткую статистику по пунктам:

-Общее количество строк
-Неразобранных строк по причине неправильного формата
-Количество успешно обработанных снимков
-Неразобранных снимков по причине неправильного формата строки
-Неизвестных типов спрайтов
-создано всего
-наблюдалось
-объектов на экране (среднее, максимум)
-доля площади астероидов (средняя, максимальная)
-разрушено астероидов
-точность стрельбы% (нижняя оценка)
-время жизни астероидов/живы в конце(не вошли в учет)
-время жизни снарядов/живы в конце(не вошли в учет)

Учитывайте:
-читается только группа объектов updatable
-усли id исчезло, то объект уничтожен
-некоторые параметры считаются неточно(особенно время жизни снарядов) из-за объектов, жизненный цикл которых находится между снимками или попадает всего на один снимок 

запуск:
python -m asteroid_analyzer (Путь к файлу со снапшотами) - обычный запуск
python -m asteroid_analyzer (Путь к файлу со снапшотами) -v - с выводом предупреждений
