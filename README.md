Анализатор для игры с астероидами.

берет снапшоты из файла формата jsonl и на основе их выводит краткую статистику по пунктам.

работает только после uv pip install -e .

Пример вывода в out.txt

Учитывайте:
-читается только группа объектов updatable.
-если id исчезло, то объект уничтожен.
-некоторые параметры считаются неточно(особенно время жизни снарядов) из-за объектов, жизненный цикл которых находится между снимками или попадает. всего на один снимок

запуск:
python -m asteroid_analyzer (Путь к файлу со снапшотами) - обычный запуск.
python -m asteroid_analyzer (Путь к файлу со снапшотами) -v - с выводом предупреждений.
